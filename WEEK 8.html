🧮 Project 1 – Python Calculator

இரண்டு numbers மற்றும் ஒரு operation-ஐ input ஆக பெற்று calculation செய்யும் calculator.

💻 Python Code

print("===== PYTHON CALCULATOR =====") print() num1 = float(input("முதல் எண்: ")) num2 = float(input("இரண்டாவது எண்: ")) print() print("1 - கூட்டல்") print("2 - கழித்தல்") print("3 - பெருக்கல்") print("4 - வகுத்தல்") choice = input("Operation தேர்வு செய்யவும்: ") if choice == "1": result = num1 + num2 print("Result:", result) elif choice == "2": result = num1 - num2 print("Result:", result) elif choice == "3": result = num1 * num2 print("Result:", result) elif choice == "4": if num2 != 0: result = num1 / num2 print("Result:", result) else: print("0-ஆல் வகுக்க முடியாது.") else: print("தவறான தேர்வு.")
📚 இந்த project-ல் பயன்படுத்தப்படும் concepts:

Variables + Input + Numbers + If/Else + Arithmetic Operations

🎓 Project 2 – Student Marks System

மாணவரின் பெயர் மற்றும் marks-ஐ பெற்று Total, Average மற்றும் Pass/Fail result காட்டும் Python program.

💻 Python Code

print("===== STUDENT MARKS SYSTEM =====") print() name = input("மாணவர் பெயர்: ") marks = [] for i in range(5): mark = float( input("Subject " + str(i + 1) + " mark: ") ) marks.append(mark) total = 0 for mark in marks: total = total + mark average = total / len(marks) print() print("===== RESULT =====") print("Student:", name) print("Total:", total) print("Average:", average) if average >= 40: print("Result: PASS") else: print("Result: FAIL")
📚 இந்த project-ல் பயன்படுத்தப்படும் concepts:

Variables + Input + Lists + For Loop + If/Else + Arithmetic
