1️⃣ Arithmetic Operations

Python-ல் கணித செயல்பாடுகளை செய்ய Arithmetic Operators பயன்படுத்தப்படுகின்றன.

Operator பெயர் Example Result
+ கூட்டல் 10 + 5 15
- கழித்தல் 10 - 5 5
* பெருக்கல் 10 * 5 50
/ வகுத்தல் 10 / 5 2.0
% மீதி 10 % 3 1
** Power 2 ** 3 8
// Floor Division 10 // 3 3

➕ 2️⃣ கூட்டல்

a = 10 b = 20 answer = a + b print("விடை:", answer)

Output: 30

➖ 3️⃣ கழித்தல்

a = 50 b = 20 answer = a - b print("விடை:", answer)

Output: 30

✖️ 4️⃣ பெருக்கல்

a = 10 b = 5 answer = a * b print("விடை:", answer)

Output: 50

➗ 5️⃣ வகுத்தல்

a = 20 b = 4 answer = a / b print("விடை:", answer)

Output: 5.0

🧮 6️⃣ Simple Calculations

Example 1 – இரண்டு எண்களின் கூட்டல்

num1 = int(input("முதல் எண்: ")) num2 = int(input("இரண்டாவது எண்: ")) total = num1 + num2 print("மொத்தம்:", total)

Example 2 – Rectangle Area

Area = Length × Width

length = float(input("நீளம்: ")) width = float(input("அகலம்: ")) area = length * width print("பரப்பளவு:", area)

Example 3 – Average

a = float(input("முதல் எண்: ")) b = float(input("இரண்டாவது எண்: ")) average = (a + b) / 2 print("சராசரி:", average)

Example 4 – Student Marks

math = int(input("கணிதம்: ")) science = int(input("அறிவியல்: ")) ict = int(input("ICT: ")) total = math + science + ict print("மொத்த மதிப்பெண்:", total)
