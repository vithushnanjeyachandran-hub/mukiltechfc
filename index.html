வாரம் 01

அடிப்படை கணினி & Setup திறன்கள்

Python programming தொடங்குவதற்கு தேவையான அடிப்படை திறன்களை முதலில் கற்றுக்கொள்வோம்.

01

🖥️ கணினி அமைப்பைப் புரிந்துகொள்ளுதல்

கணினியின் முக்கிய பகுதிகளை அறிந்துகொள்வோம்.

கணினி என்பது Data-வைப் பெற்று, அதை Process செய்து, பயனுள்ள Information-ஐ வழங்கும் ஒரு மின்னணு சாதனமாகும்.

🧠

CPU

Instructions-ஐ Process செய்கிறது

⚡

RAM

தற்காலிக Memory

💾

Storage

Files மற்றும் Programs சேமிப்பு

🔧 Hardware

கைகளால் தொடக்கூடிய கணினியின் Physical Parts. உதாரணம்: Keyboard, Mouse, Monitor, CPU, Storage.

💿 Software

கணினியில் இயங்கும் Programs. உதாரணம்: Python, VS Code, Web Browser.

💡 நினைவில் வைக்கவும்: Python என்பது ஒரு Programming Language. Keyboard மற்றும் Mouse போன்றவை Hardware.
02

⌨️ Keyboard மற்றும் Mouse அடிப்படைகள்

Programming செய்யும்போது பயன்படுத்தும் Input Devices பற்றி அறிந்துகொள்வோம்.

Keyboard மூலம் Code, Commands மற்றும் Text-ஐ Type செய்யலாம். Mouse மூலம் Files, Buttons மற்றும் Menus-ஐ Select செய்யலாம்.

ESC F1 F2 F3 F4 F5 F6 F7 F8 F9 F10 F11 F12
TAB Q W E R T Y U I O P [ ]
CAPS A S D F G H J K L ; ENTER
SHIFT Z X C V B N M , . SHIFT
CTRL ALT SPACE ALT CTRL

🖱️ Mouse

Click, Double Click, Right Click, Drag மற்றும் Drop போன்றவற்றை கற்றுக்கொள்ளுங்கள்.

⌨️ முக்கிய Shortcuts

Ctrl + C = Copy | Ctrl + V = Paste | Ctrl + S = Save

03

📁 Folders மற்றும் Files பயன்படுத்துதல்

உங்கள் Python Projects-ஐ ஒழுங்காக வைத்துக்கொள்ள கற்றுக்கொள்ளுங்கள்.

Programming Projects செய்யும்போது Files மற்றும் Folders-ஐ ஒழுங்காக வைத்திருப்பது மிகவும் முக்கியம்.

🐍 .py File

Python Program-ஐ சேமிக்க பொதுவாக .py extension பயன்படுத்தப்படுகிறது.

04

🐍 Python Install செய்வது

Python Programming செய்ய உங்கள் Computer-ஐ தயார் செய்வோம்.

Python Programs எழுதுவதற்கு முதலில் உங்கள் Computer-ல் Python Install செய்யப்பட்டிருக்க வேண்டும். Code எழுத VS Code-ஐ பயன்படுத்தலாம்.

1

Python Install

Computer-ல் Python Install செய்யுங்கள்.

2

VS Code Install

Visual Studio Code Install செய்யுங்கள்.

3

Python Extension

VS Code-ல் Python Extension சேர்க்கவும்.

4

.py File

உங்கள் முதல் Python File உருவாக்குங்கள்.

💡 VS Code Tip: Python Extension Install செய்த பிறகு, VS Code கேட்கும்போது சரியான Python Interpreter-ஐ தேர்வு செய்யுங்கள்.
05

💻 உங்கள் முதல் Python Program

முதல் Python Code-ஐ எழுதி Run செய்வோம்.

Python-ல் Screen-ல் ஒரு தகவலைக் காட்ட print() function பயன்படுத்தப்படுகிறது.

Example 01 — Hello World
hello.py 
print("Hello, World!")
OUTPUT
Hello, World!
Example 02 — பல வரிகளை Print செய்வது
welcome.py 
print("Python-க்கு வரவேற்கிறோம்!")
print("நான் Python கற்றுக்கொள்கிறேன்.")
OUTPUT
Python-க்கு வரவேற்கிறோம்!
நான் Python கற்றுக்கொள்கிறேன்.
💡 நினைவில் வைக்கவும்: Python Program-ஐ Run செய்தால், Python Instructions-ஐ Computer செயல்படுத்தும்.
📝

நீங்களே செய்து பாருங்கள்

my_first_program.py என்ற File உருவாக்கி கீழே உள்ள Program-ஐ எழுதிப் பாருங்கள்.

my_first_program.py 
print("என் பெயர் ______")
print("நான் Python கற்றுக்கொள்கிறேன்.")
print("இது Python Week 1.")
🎯 Challenge: மேலே உள்ள Code-ல் உங்கள் பெயர், பாடசாலை மற்றும் உங்களுக்கு பிடித்த பாடத்தை Print செய்ய மாற்றிப் பாருங்கள்.
