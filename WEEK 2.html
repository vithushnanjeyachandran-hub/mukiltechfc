1️⃣ Variables – மாறிகள்

ஒரு தகவலை ஒரு பெயருடன் சேமித்து வைக்க Python-ல் Variable பயன்படுத்தப்படுகிறது.

name = "Vithu" age = 15 print(name) print(age)

📌 இன்னொரு Example

student_name = "Kumar" student_age = 14 school = "ABC School" print(student_name) print(student_age) print(school)
💡 Variable பெயர் எண்ணுடன் ஆரம்பிக்கக்கூடாது.

2️⃣ Numbers & Strings

🔢 Integer

age = 15 marks = 90

முழு எண்கள் Integer.

🔢 Float

price = 250.50 height = 5.6

தசம எண்கள் Float.

🔤 String

name = "Vithu" city = "Jaffna"

Text தகவல்கள் String.

3️⃣ Input & Output

📤 print()

print("வணக்கம்!") print("Python கற்கலாம்")

📥 input()

name = input("உங்கள் பெயர்: ") print("வணக்கம்", name)

🔢 Number Input

age = int(input("உங்கள் வயது: ")) print("வயது:", age)

🧮 இரண்டு எண்களை கூட்டுதல்

a = int(input("முதல் எண்: ")) b = int(input("இரண்டாவது எண்: ")) answer = a + b print("விடை:", answer)
