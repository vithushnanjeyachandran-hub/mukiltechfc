1️⃣ Problem Solving என்றால் என்ன?

ஒரு பிரச்சினைக்கு சரியான தீர்வை கண்டுபிடித்து, அதை Python code ஆக மாற்றுவது Problem Solving என்று அழைக்கப்படுகிறது.

🧠 Example Problem

ஒரு மாணவரின் mark-ஐ input ஆக பெற்று, அவர் Pass அல்லது Fail என்பதை கண்டுபிடிக்க வேண்டும்.

Step 1 – Input

mark = int(input("மதிப்பெண்: "))

Step 2 – Condition

if mark >= 40: print("Pass") else: print("Fail")

Step 3 – Complete Program

mark = int(input("மதிப்பெண்: ")) if mark >= 40: print("Pass") else: print("Fail")

2️⃣ Combining Concepts

பெரிய problem-களை தீர்க்க பல Python concepts-ஐ ஒன்றாக பயன்படுத்த வேண்டும்.

Example – 5 Marks

5 marks-ஐ input ஆக பெற்று, ஒவ்வொரு mark-க்கும் Pass / Fail காட்டுவோம்.

marks = [] for i in range(5): mark = int(input("Mark: ")) marks.append(mark) for mark in marks: if mark >= 40: print(mark, "→ Pass") else: print(mark, "→ Fail")
💡 இங்கே 4 concepts ஒன்றாக பயன்படுத்தப்பட்டுள்ளது:

List + Input + For Loop + If/Else

🐛 3️⃣ Debugging என்றால் என்ன?

Python code-ல் இருக்கும் தவறுகளை கண்டுபிடித்து சரி செய்வது Debugging என்று அழைக்கப்படுகிறது.

🐛 Bug என்றால் என்ன?

Program சரியாக வேலை செய்யாமல் இருப்பதற்கு காரணமாக இருக்கும் code-ல் உள்ள தவறு Bug என்று அழைக்கப்படுகிறது.

❌ Example – Syntax Error

print("Hello"

இங்கே closing ) இல்லை.

✅ Correct Code

print("Hello")

❌ Example – Variable Error

name = "Vithu" print(nam)

Variable பெயர் name. ஆனால் print செய்யும்போது nam என்று எழுதப்பட்டுள்ளது.

✅ Correct Code

name = "Vithu" print(name)

❌ Example – Indentation Error

if mark >= 40: print("Pass")

✅ Correct Code

if mark >= 40: print("Pass")
💡 Error message-ஐ பயப்பட வேண்டாம்.

Python காட்டும் error message-ஐ படித்தால் எந்த இடத்தில் problem இருக்கிறது என்பதை கண்டுபிடிக்க உதவும்.

🔍 4️⃣ Debugging செய்யும் முறைகள்

Step 1️⃣ – Error message-ஐ படிக்கவும்

Python கொடுக்கும் error message-ஐ கவனமாக படிக்கவும்.

Step 2️⃣ – Error line-ஐ பார்க்கவும்

எந்த line-ல் error வந்திருக்கிறது என்று பார்க்கவும்.

Step 3️⃣ – Variable names சரிபார்க்கவும்

spelling மற்றும் variable பெயர்கள் சரியாக உள்ளதா என்று பார்க்கவும்.

Step 4️⃣ – Indentation சரிபார்க்கவும்

if, for போன்றவற்றின் உள்ளே உள்ள code சரியாக space கொடுக்கப்பட்டுள்ளதா என்று பார்க்கவும்.

Step 5️⃣ – மீண்டும் Run செய்யவும்

Error சரி செய்த பிறகு program-ஐ மீண்டும் run செய்யவும்.

5️⃣ Simple Problem Solving Examples

Example 1 – Even / Odd

number = int(input("ஒரு எண்ணை உள்ளிடுங்கள்: ")) if number % 2 == 0: print("Even Number") else: print("Odd Number")

Example 2 – பெரிய எண்ணைக் கண்டுபிடித்தல்

a = int(input("முதல் எண்: ")) b = int(input("இரண்டாவது எண்: ")) if a > b: print("பெரிய எண்:", a) else: print("பெரிய எண்:", b)

Example 3 – List-ல் Pass Students

students = ["Arun", "Vithu", "Siva"] marks = [75, 35, 80] for i in range(3): if marks[i] >= 40: print(students[i], "→ Pass") else: print(students[i], "→ Fail")

Example 4 – Total மற்றும் Average

marks = [70, 80, 60, 90, 75] total = 0 for mark in marks: total = total + mark average = total / len(marks) print("Total:", total) print("Average:", average)

🏆 Mini Project – Student Mark Analyzer

5 மாணவர்களின் marks-ஐ பெற்று, Total, Average மற்றும் ஒவ்வொரு மாணவரின் Pass / Fail result-ஐ காட்டும் Python program உருவாக்குங்கள்.

💻 Python Code

students = [] marks = [] for i in range(5): name = input("மாணவர் பெயர்: ") mark = int(input("மதிப்பெண்: ")) students.append(name) marks.append(mark) total = 0 for mark in marks: total = total + mark average = total / len(marks) print() print("===== RESULT =====") for i in range(5): if marks[i] >= 40: result = "Pass" else: result = "Fail" print( students[i], "→", marks[i], "→", result ) print() print("Total:", total) print("Average:", average)
