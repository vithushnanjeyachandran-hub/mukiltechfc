1️⃣ Condition என்றால் என்ன?

ஒரு குறிப்பிட்ட நிபந்தனை உண்மையா அல்லது பொய்யா என்பதை Python சரிபார்ப்பதே Condition ஆகும்.

📌 Example

age = 18 if age >= 18: print("நீங்கள் 18 அல்லது அதற்கு மேற்பட்டவர்")
💡 இங்கே Python முதலில் age >= 18 என்பதை சரிபார்க்கிறது. அது True என்றால் print() இயங்கும்.

2️⃣ if Statement

ஒரு condition True ஆக இருந்தால் ஒரு குறிப்பிட்ட code-ஐ இயக்க if பயன்படுத்தப்படுகிறது.

Example

number = 10 if number > 5: print("Number 5-ஐ விட பெரியது")

🔍 Comparison Operators

== சமம் != சமம் இல்லை > பெரியது < சிறியது >= பெரியது அல்லது சமம் <= சிறியது அல்லது சமம்
⚠️ Python-ல் condition முடிவில் : (colon) போட வேண்டும்.

3️⃣ else Statement

if condition False ஆக இருந்தால் else பகுதி இயங்கும்.

age = 15 if age >= 18: print("Adult") else: print("Not Adult")

இங்கே age = 15 என்பதால் condition False. அதனால் else இயங்கும்.

4️⃣ Pass / Fail Program

மாணவரின் மதிப்பெண்ணை input மூலம் பெற்று, அவர் Pass அல்லது Fail என்பதை கண்டறியலாம்.

📌 Rule

40 அல்லது அதற்கு மேல் → Pass

40-க்கு கீழ் → Fail

💻 Python Program

marks = int(input("மதிப்பெண்: ")) if marks >= 40: print("Pass") else: print("Fail")
✅ marks = 75
Result: Pass
❌ marks = 25
Result: Fail

5️⃣ இன்னும் சில Examples

Example 1 – Positive / Negative

number = int(input("ஒரு எண்ணை உள்ளிடுங்கள்: ")) if number >= 0: print("Positive Number") else: print("Negative Number")

Example 2 – Even / Odd

number = int(input("ஒரு எண்ணை உள்ளிடுங்கள்: ")) if number % 2 == 0: print("Even Number") else: print("Odd Number")

Example 3 – Voting Age

age = int(input("உங்கள் வயது: ")) if age >= 18: print("Vote செய்யலாம்") else: print("Vote செய்ய முடியாது")
