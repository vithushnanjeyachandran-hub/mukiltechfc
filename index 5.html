1️⃣ Loop என்றால் என்ன?

ஒரு செயலை மீண்டும் மீண்டும் செய்ய பயன்படுத்தப்படும் programming structure தான் Loop.

❌ Loop இல்லாமல்

print("Hello") print("Hello") print("Hello") print("Hello") print("Hello")

✅ Loop பயன்படுத்தி

for i in range(5): print("Hello")
💡 ஒரே code-ஐ 5 முறை எழுதுவதற்கு பதிலாக, Loop பயன்படுத்தி ஒரு முறை மட்டும் எழுதலாம்.

2️⃣ For Loop

Python-ல் ஒரு செயலை குறிப்பிட்ட எண்ணிக்கையில் மீண்டும் செய்ய for loop பயன்படுத்தலாம்.

📌 Basic Syntax

for variable in sequence: # செய்ய வேண்டிய code

Example

for i in range(5): print(i)

Output:

0 1 2 3 4
⚠️ range(5) என்பது 0 முதல் 4 வரை கொடுக்கும். 5 சேராது.

3️⃣ range() Function

For loop-ல் எத்தனை முறை loop இயங்க வேண்டும் என்பதை குறிப்பிட range() பயன்படுத்தலாம்.

range(5)

for i in range(5): print(i)

Output: 0, 1, 2, 3, 4

range(1, 6)

for i in range(1, 6): print(i)

Output: 1, 2, 3, 4, 5

range(2, 11, 2)

for i in range(2, 11, 2): print(i)

Output: 2, 4, 6, 8, 10

4️⃣ For Loop Examples

Example 1 – 1 முதல் 10 வரை

for i in range(1, 11): print(i)

Example 2 – 1 முதல் 5 வரை கூட்டல்

total = 0 for i in range(1, 6): total = total + i print("மொத்தம்:", total)

Example 3 – ஒரு பெயரை 5 முறை காட்டுதல்

for i in range(5): print("Vithu")

Example 4 – Even Numbers

for i in range(2, 11, 2): print(i)

Example 5 – Multiplication Table

number = int(input("எந்த எண்ணின் Table வேண்டும்? ")) for i in range(1, 11): print(number, "x", i, "=", number * i)

5️⃣ Repeating Actions

ஒரே செயலை மீண்டும் மீண்டும் செய்ய loop மிகவும் பயனுள்ளதாக இருக்கும்.

🎯 Example – 10 முறை Welcome

for i in range(10): print("Welcome to Python!")

🎯 Example – 5 மாணவர்களின் பெயர்

for i in range(5): name = input("மாணவர் பெயர்: ") print("வணக்கம்", name)
💡 Loop-ன் உள்ளே இருக்கும் code ஒவ்வொரு iteration-லும் மீண்டும் இயங்கும்.

🏆 Mini Project – Multiplication Table

User-இடமிருந்து ஒரு எண்ணை பெற்று, அந்த எண்ணின் multiplication table-ஐ 1 முதல் 10 வரை காட்டுங்கள்.

💻 Python Code

number = int(input("எந்த எண்ணின் Table வேண்டும்? ")) for i in range(1, 11): result = number * i print(number, "x", i, "=", result)

User-இடமிருந்து ஒரு எண்ணைப் பெற்று, அந்த எண்ணின் Table-ஐ 1 முதல் 20 வரை காட்டும் program உருவாக்குங்கள்.
