1️⃣ List என்றால் என்ன?

பல values-ஐ ஒரே variable-ல் சேமித்து வைக்க Python List பயன்படுகிறது.

📌 Example

fruits = ["Apple", "Banana", "Mango"] print(fruits)

Output:

["Apple", "Banana", "Mango"]
💡 List-ல் பல items-ஐ [ ] square brackets உள்ளே எழுதுகிறோம்.

2️⃣ List-ல் Items சேர்த்தல்

ஏற்கனவே உள்ள List-ல் புதிய item சேர்க்க append() பயன்படுத்தலாம்.

📌 append()

fruits = ["Apple", "Banana"] fruits.append("Mango") print(fruits)

Output:

["Apple", "Banana", "Mango"]

📌 இன்னொரு Example

students = [] students.append("Kumar") students.append("Arun") students.append("Vithu") print(students)
💡 append() பயன்படுத்தினால் List-ன் முடிவில் புதிய item சேரும்.

3️⃣ List-ல் உள்ள Items-ஐ படித்தல்

List-ல் உள்ள ஒரு item-ஐ அதன் index மூலம் பெறலாம்.

📌 Index

fruits = ["Apple", "Banana", "Mango"] print(fruits[0]) print(fruits[1]) print(fruits[2])

Output:

Apple Banana Mango
⚠️ Python-ல் List index 0-ல் ஆரம்பிக்கும்.

முதல் item → index 0
இரண்டாவது item → index 1
மூன்றாவது item → index 2

4️⃣ List + For Loop

List-ல் உள்ள அனைத்து items-ஐ ஒன்றன் பின் ஒன்றாக படிக்க For Loop பயன்படுத்தலாம்.

fruits = ["Apple", "Banana", "Mango"] for fruit in fruits: print(fruit)

Output:

Apple Banana Mango

🎓 Student Names Example

students = ["Kumar", "Arun", "Vithu", "Siva"] for student in students: print("Student:", student)

5️⃣ Input மூலம் List உருவாக்குதல்

User-இடமிருந்து பெயர்களைப் பெற்று List-ல் சேர்க்கலாம்.

students = [] for i in range(3): name = input("மாணவர் பெயர்: ") students.append(name) print("மாணவர்கள்:") for student in students: print(student)
💡 இங்கே இரண்டு concepts ஒன்றாக பயன்படுத்தப்படுகின்றன:

List + append() + for loop
